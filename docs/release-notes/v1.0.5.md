# OpenCode 账号管理 v1.0.5

首个开源版本：源码、Windows exe 和 Ubuntu .deb 安装包都在本仓库发布，MIT 许可证。

## 新增

- **Ubuntu .deb 安装包**：装在 `/opt/opencode-account-manager`，在应用程序列表里可以找到。
- **程序内升级支持 .deb 安装版**：检查更新 → 下载（进度条）→ 校验 SHA-256 → 程序退出 → 管理员授权 → 自动安装 → 自动启动新版。
- 导出账号时保存对话框的默认文件名带日期时间：`opencode_年-月-日_时-分-秒.json`，与 WebDAV 上传的命名一致。
- 屏幕较小或系统缩放较大时，主界面整体按比例缩小，不再超出屏幕、也不再出现无法最大化。

## 调整

- 去掉“系统代理”开关、状态栏的代理状态与“重新应用”，以及设置里的代理地址和桌面版路径。OAuth 授权和额度查询沿用系统默认代理。
- 修复行内“切号 / 查询 / 删除”只显示下边线、像下划线的问题（行分隔线样式误套到了按钮和额度格上）。
- 点击单个账号后面的“查询”不再取消该行的勾选。
- Linux 的字体与 Windows 保持一致：英文用内置 Inter，中文用系统黑体类字体补齐。
- Linux 下订阅到期日读取修复。

## 校验

每个文件旁有同名 `.sha256`。升级时程序会自动校验。
