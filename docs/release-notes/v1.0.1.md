# OpenCode 账号管理 v1.0.1

Windows x64 便携版，无需安装 .NET。

## 升级功能

- 启动静默检查更新，主界面与托盘均可手动检查。
- 确认升级后自动下载，显示百分比与 MB 进度；下载时可取消。
- 下载完成后校验 SHA256、文件长度、Windows x64 类型和版本，再自动重启进入新版。
- 下载取消、校验失败和替换失败时停止升级；失败回滚与单实例交接经过隔离回归验证。
- 保留本地账号、设置和日志；修复取消或失败后旧进度报告干扰提示的问题。

## 其它功能

保留账号管理、额度查询、自动刷新当前、可选自动切号、托盘常驻及 OpenCode 系统代理检测/修复。代理检测忽略 Electron 子进程的精简环境，避免误报。

## 下载与迁移

下载 `OpenCodeAccountManager-win-x64.exe`。第一次从旧工具迁移时，请从托盘退出旧工具，将新 EXE 放入原目录（可改名为 `OpenCodeAccountManager.exe`），保留原设置文件，再启动。以后可在程序中确认升级。

本 Release 仅包含 EXE 与 SHA256 校验文件，不含个人账号、配置、日志或备份。
