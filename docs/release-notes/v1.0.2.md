# OpenCode 账号管理 v1.0.2

Windows x64 便携版，无需安装 .NET。

## 本次修复

- GitHub 匿名 API 限流时，自动改用公开发布页面检查版本，避免共享代理出口配额耗尽导致检查更新失败。
- 更新过程无需 GitHub 登录或令牌；下载仍严格校验地址、SHA256、文件长度、Windows x64 类型及版本。

## 升级流程

发现新版 → 确认升级 → 自动下载并显示百分比与 MB 进度 → 校验成功 → 自动重启到新版。下载阶段可取消，替换失败尝试恢复旧版，账号、设置和日志保留。

本版包含已通过真实单文件 EXE 和完整 Avalonia 界面回归的升级交接修复、进度状态修复及托盘退出兜底。

## 下载与迁移

下载 `OpenCodeAccountManager-win-x64.exe`。首次从旧工具迁移时，请从托盘退出旧工具，将新 EXE 放入原目录（可改名为 `OpenCodeAccountManager.exe`），保留原设置文件，再启动。

发布资产只有 EXE 和 SHA256 文件，不含个人账号、配置、日志或备份；
