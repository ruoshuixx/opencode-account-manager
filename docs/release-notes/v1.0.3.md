# OpenCode 账号管理 v1.0.3

Windows x64 便携版，无需安装 .NET。

## 本次调整

- 更新检查改为仅在主界面或托盘手动触发，移除“启动时检查更新”设置项；不再在启动时联网检查。
- 导入账号统一为直接覆盖式完整导入，移除“仅更新订阅（保留现有令牌）”选项，界面更简单。

## 升级流程

点击“检查更新” → 发现新版 → 确认升级 → 自动下载并显示百分比与 MB 进度 → 校验成功 → 自动重启到新版。下载阶段可取消，替换失败尝试恢复旧版，账号、设置和日志保留。

## 保持的修复

- GitHub 匿名 API 限流（403/429）时，自动从公开发布页面检查版本，无需登录或令牌。
- 真实单文件 EXE 交接、超时回滚与完整 Avalonia 界面升级回归均已通过。

## 下载与迁移

下载 `OpenCodeAccountManager-win-x64.exe`。首次从旧工具迁移时，请从托盘退出旧工具，将新 EXE 放入原目录（可改名为 `OpenCodeAccountManager.exe`），保留原设置文件，再启动。

发布资产只有 EXE 和 SHA256 文件，不含个人账号、配置、日志或备份；
