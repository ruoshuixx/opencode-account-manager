# OpenCode 账号管理 v1.0.0

首个正式 Windows x64 便携版，无需安装 .NET。

## 本版更新

- 内置 GitHub 更新：启动静默检查，确认升级后自动下载，显示百分比与 MB 进度，校验成功后重启到新版。
- 主界面、托盘增加“检查更新”，设置可关闭启动检查。
- 使用 SHA256、文件长度、Windows x64 类型及版本校验；更新失败提示错误，替换失败尝试恢复旧版。
- 修复系统代理误报：忽略 Electron 子进程的精简环境。
- 保留托盘常驻、额度显示、自动刷新当前与可选自动切号等功能。
- 单文件压缩，EXE 约 44 MB。

## 下载与迁移

下载 `OpenCodeAccountManager-win-x64.exe`。从尚无升级功能的旧版迁移时，请先从托盘退出旧工具，将新 EXE 放入原目录（可改名为 `OpenCodeAccountManager.exe`），保留原设置文件，再启动新版。以后可直接在程序中确认升级。

本 Release 仅有 EXE 与 SHA256 校验文件，不含个人账号、配置、日志或备份。
